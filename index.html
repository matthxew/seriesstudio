About Field Studio

Field Studio is a workflow tool built for documentary photographers. Unlike commercial photographer CRMs, it does not assume your subject is a paying client.

Custom dimensions per series let you define exactly what matters for your project. Coverage views show whether your project is balanced or gappy against your own targets.

v1.1 — single user mode running locally. The data model is multi-user and team aware so the tool can grow into a shared workspace later.
