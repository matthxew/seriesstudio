About Series Studio

Series Studio is a workflow tool built for documentary photographers. Unlike commercial photographer CRMs, it does not assume your subject is a paying client.

Custom dimensions per series let you define exactly what matters for your project. Coverage views show whether your project is balanced or gappy against your own targets.

v1.3 — single user mode running locally. The data model is multi-user and team aware so the tool can grow into a shared workspace later.

Data

Browser-only storage. All Series Studio data (series, subjects, deadlines, settings) lives in this browser's local storage; attachments (release forms, moodboard images) live in this browser's IndexedDB. Nothing is synced to a server.
If you switch browsers, devices, profiles, or computers — or if you clear site data — your work won't follow. To move between browsers: Export here, then Import the file in the new browser.
The export bundles your attachments inline (base64), so a single file carries everything across.
Tip: take a fresh export every time you finish a shoot day. Exports are timestamped — keep the last few.
