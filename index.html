About Field Studio

Field Studio is a workflow tool built for documentary photographers. Unlike commercial photographer CRMs (Honeybook, Studio Ninja, Tave), it does not assume your subject is a paying client. The core verb is "build relationships with sitters whose stories carry wider truths," not "send the invoice."

Custom dimensions per series let you define exactly what matters for your project: generation, geography, age range, profession, faith, language, club affiliation, anything. Coverage views show whether your project is balanced or gappy against your own targets.

This is v1, single user mode running locally. The data model is multi-user and team aware so the tool can grow into a shared workspace later.
